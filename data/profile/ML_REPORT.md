# 实验三 · 人工智能算法：降水预测实验结果

## 实验设置

- 数据集：GlobalWeatherRepository（清洗后 165,952 条观测，覆盖 268 城）
- 预测任务：二分类——当前是否降水（标签规则：`precip_mm > 0.1`）
- 类别分布：无降水 139,239 条 / 降水 26,713 条
- 特征工程：17 维特征，含时间周期编码（month_sin/cos）与衍生特征（体感温差、阵风比、湿度云量交互）
- 数据划分：分层抽样训练集 25,000 条、测试集 10,000 条（random_state=42）
- 评估指标：准确率、精确率、召回率、F1、AUC、训练耗时

## 各算法说明

**逻辑回归**：线性模型，对标准化特征拟合降水概率的对数几率；训练快、可解释性强，是分类任务的基准线。
  测试集表现：准确率 0.8435、召回率 0.1870、F1 0.2778、AUC 0.8419，训练耗时 0.05 秒。

**决策树**：单棵决策树（限深 8 层），按信息增益递归划分；可解释性好，但单树容易欠拟合或过拟合。
  测试集表现：准确率 0.8599、召回率 0.4211、F1 0.4918、AUC 0.8503，训练耗时 0.12 秒。

**随机森林**：Bagging 集成：200 棵随机化决策树投票；方差低、鲁棒性强，并提供特征重要性。
  测试集表现：准确率 0.8795、召回率 0.3994、F1 0.5163、AUC 0.8972，训练耗时 0.93 秒。

**K近邻**：K 近邻（K=15，欧氏距离），惰性学习无显式训练过程；对特征量纲敏感，需先标准化。
  测试集表现：准确率 0.8575、召回率 0.2789、F1 0.3866、AUC 0.8489，训练耗时 0.01 秒。

**朴素贝叶斯**：高斯朴素贝叶斯，假设特征条件独立；训练极快，在特征相关性较强时估计偏保守。
  测试集表现：准确率 0.6633、召回率 0.8478、F1 0.4478、AUC 0.8028，训练耗时 0.01 秒。

**支持向量机**：支持向量机（RBF 核），最大化间隔非线性分类；对小样本效果好，训练开销随样本数超线性增长。
  测试集表现：准确率 0.8651、召回率 0.2876、F1 0.4070、AUC 0.8370，训练耗时 5.54 秒。

**梯度提升**：Boosting 集成：逐棵拟合残差（学习率 0.05、200 轮）；偏差低，对超参数较敏感。
  测试集表现：准确率 0.8734、召回率 0.3547、F1 0.4743、AUC 0.8872，训练耗时 9.59 秒。

**LightGBM**：LightGBM 梯度提升（ leaf-wise 生长、直方图加速），工业界主流；速度快、精度高。
  测试集表现：准确率 0.8845、召回率 0.4801、F1 0.5724、AUC 0.9062，训练耗时 0.92 秒。

## 结果分析

1. **最佳模型：LightGBM**（按 F1 选取）。树集成方法（随机森林 / 梯度提升 / LightGBM）整体优于线性与概率模型，说明降水与气象特征之间存在明显的非线性关系与特征交互。
2. **混淆矩阵解读（最佳模型）**：真负例 8,072、假正例 318、假负例 837、真正例 773。相对而言假负例（有雨报成无雨）对出行场景影响更大，可通过调整分类阈值用部分精确率换取更高召回率。
3. **特征重要性**：湿度、云量及其交互项、能见度是降水预测最主要的驱动特征，符合气象常识；温度类特征贡献次之。
4. **效率对比**：概率模型（朴素贝叶斯、逻辑回归）训练最快；SVM 与梯度提升训练开销最大，这也是工程上常以 LightGBM 作为折中的原因。

> 说明：本实验为课程演示，采用分层抽样控制训练开销；所有模型在同一训练/测试划分上评估，结果可直接横向对比。
